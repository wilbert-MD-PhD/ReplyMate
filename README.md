# ReplyMate · 答伴

**用自己的资料，准备会议问答与英文面试。**

**首字目标：提交问题后 3 秒内输出第一个字。**

快速回答先显示，深度回答独立补充。支持语音输入，可将问题译成中文，并支持问答回看。界面为中文，回答默认使用英文。

## 快速开始

1. **安装并打开。** Mac 打开 DMG，将 ReplyMate 拖入“应用程序”后打开。Windows 运行安装文件。答伴会在默认浏览器打开，无需自行安装 Node.js 或使用命令行。
2. **体验示例。** 点击页面下方的预设问题，即可离线查看问答界面，不需要登录。
3. **启用 AI。** 点击 **启用 AI 回答**，在组件中心确认下载并安装。完成后点击 **登录 ChatGPT**，在官方页面授权。连接成功后自动预热，顶部显示状态与进度，预热会消耗账号额度。
4. **放入资料。** 点击 **选择资料**，或拖入文件。TXT、Markdown、资料 JSON 可直接导入，Word／PPT、PDF 首次使用需安装对应组件。
5. **开始提问。** 输入问题，点击 **立即回答**，或按 `Ctrl+Enter` / `Command+Enter`。需要语音时，再选择浏览器转写或安装本地语音组件。

**首次安装提示：** 当前安装包未使用开发者证书签名及 Apple 公证，系统可能提示未识别开发者，单位管理的电脑可能限制运行。

## 核心功能与组件

| 功能 | 需要安装什么 | 联网要求 |
| --- | --- | --- |
| 示例演示、手动输入、TXT／Markdown／JSON 导入 | 主程序即可 | 可离线 |
| 快速回答、独立深度回答、中文问题翻译 | AI 回答组件 | 需要联网、Codex 账号权限及可用额度 |
| Word／PowerPoint 文字提取 | Word 与 PowerPoint 组件 | 安装后在本机解析 |
| PDF 文字提取 | PDF 文字读取组件 | 安装后在本机解析，不含 OCR |
| 浏览器语音转写 | 支持语音识别的浏览器及麦克风权限 | 可能使用浏览器的云端服务 |
| 本地语音转写 | Whisper 引擎和一个语音模型 | 安装后可离线转写 |

组件中心支持暂停、续传、修复、卸载和手动导入。本地语音默认推荐 Turbo 多语言模型，模型本身约 574 MB，引擎另行安装；也可按设备条件选择较小模型。同一多语言模型切换识别语言无需重新下载。

- **快速回答与深度回答同时开始。** 快速通道默认让两个可用模型竞速，深度模型独立回答。较慢的深度回答不阻塞下一题。
- **三秒首字目标。** 目标为提交问题后 3 秒内显示快速回答的第一个正文字符，实际用时逐题显示。当前版本的真实账号达标率仍待验证，演示和预设答案不计入 AI 成绩。[性能口径与历史测试](docs/latency-benchmark.md)。
- **支持多语言输入。** 可选择语音识别语言，当前回答默认使用英文。多语言模型按所选语言识别，英语专用模型仅支持英语。各语种识别质量仍需分别验证。
- **回看与重答。** 支持回看本次问答、修改问题后重答、单独重答深度回答，以及使用自己核对过的预设快答。

## 账号与隐私

AI 功能需要支持 Codex 的账号权限及可用额度。模型竞速、深度回答、中文翻译和自动预热都会消耗你的额度，离线演示不消耗。账号可用模型以实际调用权限为准。

账号授权由安装的官方 Codex 组件处理。在官方页面授权，无需向答伴填写密码或复制令牌。资料、备份和账号状态保存在本机独立的应用数据目录。

- 文档在本机提取文字。本地 Whisper 模式的音频留在本机，不自动切换到在线识别。
- 浏览器语音识别可能把音频发送给浏览器供应商。
- **启用 AI 回答后，问题、近期问题、转写候选、资料摘要和相关片段会发送到模型服务。** 使用本地语音转写也遵循这一规则，服务端保留规则取决于该服务。
- 界面服务仅监听本机回环地址。当前问答和录音保存在页面内存，刷新或关闭页面后清空。

## 常见问题

**能读取扫描 PDF、图片和图表吗？**

目前只提取可读取的文字，不包含 OCR，也不解释图表和公式。请先转成文字或补充说明。没有可读取文字时会提示导入失败，并保留原资料。

**能导入多份资料吗？更换资料会怎样？**

支持多选或拖入多个文件，文件数量与大小不限额。可追加到现有资料库或替换整个资料库，默认追加。整批校验通过后保存并备份旧库，任一文件失败则保留原库。导入成功后清空当前页面问答，请先复制需要保留的回答。首次导入不混入示例资料，追加时保留已有预设问答。[资料格式、限制与预设问答](docs/library-format.md)。

**中文问题能检索英文资料吗？**

输入支持中文等非拉丁文字，但相关片段使用同语言词面匹配，尚不具备跨语言语义检索。资料摘要仍会发送给 AI。建议让问题与关键资料片段使用相同语言，并核对答案依据。

**登录后没有某个模型怎么办？**

只有一个快速模型可用时，软件显示单模型模式。默认深度模型不可用时，需要在模型设置中选择可用模型。模型列表不保证每个模型都可调用，权限和额度以实际请求为准。

**没有语音识别，也能使用吗？**

可以随时手动输入。浏览器识别取决于设备和浏览器支持，可尝试 Chrome 或 Edge。使用本地识别需安装引擎与模型，在“组件与本地语音”中应用模型和语言，确认就绪后开始收音。按 `Esc` 暂停。

**关闭标签页就是退出吗？资料会删除吗？**

关闭浏览器标签页后，答伴仍在后台运行。请点击页面底部 **退出答伴**，或从菜单栏／系统托盘退出。关闭页面会清空本次问答与录音，导入资料和登录状态保留。退出账号不删除资料。

## 开发与更多说明

源码运行需要 Node.js 22.13 或更新版本。在源码目录执行：

```sh
npm ci --ignore-scripts
npm start
```
