# ReplyMate 2.5.0 · 轻量主程序与组件中心

主程序支持离线打开、演示、手动输入，以及 TXT、Markdown、资料 JSON 导入。AI 回答、Word／PowerPoint、PDF 和本地语音引擎改为在组件中心按需安装。首次打开不自动下载组件。

已安装 AI 组件并登录账号后，软件启动即自动预热竞速快答、独立深答和中文辅助。顶部持续显示等待条件、预热进度、完成或错误，可手动重试。预热使用实际答题会话，会消耗账号额度。首页醒目显示“3 秒内输出第一个答案字符”的性能目标，每题单列提交至快速回答首字用时。目标不等于速度保证，预设答案不计作 AI 首字成绩。

组件下载采用固定清单、流式写盘和 SHA-256 校验，支持暂停、续传、取消、手动导入、重新校验、修复、卸载及保留版本回滚。安装中断或自检失败不会启用半包。更新主程序时保留账号、资料、备份、设置和已安装组件。

本地语音默认推荐 Whisper Turbo 多语言 Q5_0（574,041,195 字节）。另有 Small、Base、Tiny 的多语言和英语专用版本。识别语言单独选择并持久化，同一多语言权重切换语言不重复下载。模型安装后，应用模型时加载并执行短音频自检，只有成功后才显示本地语音就绪。英语专用版只支持英语。

本地模式只向回环服务发送录音，不自动切换到在线识别。浏览器模式可能由浏览器云端处理音频。开启 AI 回答后，问题文字与必要参考资料仍会发送到模型服务。回答继续默认使用英文，中文辅助接收原语言问题。

固定模型目录来自 Hugging Face 固定修订，运行组件由同版本构建产出，与主程序一起发布。发布前可使用组件中心的“手动导入”测试同批构建附件。在线更新目录尚未启用，目录更新随主程序发布，避免接收未经签名验证的外部可执行清单。

首版继续使用 Electron。Codex 保留完整运行目录，PDF 保留文字读取所需资源及本平台 Canvas，未把尚未验证的裁剪收益记入成果。扫描 PDF 不含 OCR，会提示未提取到文字。

分平台构建、自动测试、真实账号、真实麦克风、分语言质量和 30 分钟连续收音分别记录。仅完成的项目可记为通过。未签名的开发构建不能视为已通过正式分发与系统签名验收。
