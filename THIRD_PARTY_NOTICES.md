# External components

This repository has no third-party npm runtime dependencies and bundles no model weights or media.
Its demo notes are fictional content provided with the application under the MIT license.

Users install these components separately as needed:

- [Node.js](https://github.com/nodejs/node): JavaScript runtime.
- [Codex CLI](https://github.com/openai/codex): optional AI backend.
- [whisper.cpp](https://github.com/ggml-org/whisper.cpp): optional local speech recognition.
- Speech model weights: downloaded separately from the chosen model distributor.
- Browser speech recognition: provided by the user's browser/vendor.

These components and services retain their own licenses and terms. This project's MIT license covers
only the files in this repository and does not grant rights to third-party models or services.
